صفحة الطلب

هذه الصفحة مخصصة لتثبيت الطلب بشكل واضح: ماذا تطلبين، كيف يتم التأكيد، ومتى يصلك الطلب.

العرض الحالي: باقة شموخ كير 400 ₪

تشمل المنتجات الأساسية (غزير + ماسك السدر + حرير) مع 5 هدايا. الدفع عند الاستلام داخل فلسطين.

1) إرسال البيانات

أرسلي الاسم، رقم الهاتف، والمدينة عبر واتساب مع عبارة "أريد طلب باقة شموخ".

2) تأكيد الطلب

فريق شموخ كير يؤكد التفاصيل النهائية وتكلفة الشحن (إن وجدت) ووقت التسليم المتوقع.

3) الاستلام والدفع

يتم الدفع عند الاستلام حسب سياسة الإطلاق الحالية.

سياسة الطلب والتوصيل

  • التوصيل داخل فلسطين فقط في المرحلة الحالية.
  • أي طلب تعديل بعد التأكيد يتم عبر نفس محادثة واتساب.
  • للاسترجاع راجعي سياسة الاسترجاع.
